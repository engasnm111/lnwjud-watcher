# Changelog

## 0.1.0 - 2026-09-24

Initial preview release.

- Web/PWA, Android, and iOS from one shared React/TypeScript codebase.
- Read-only Watcher Protocol v1 client with runtime validation.
- Reconnecting live activity stream and evidence-based goal progress.
- Overview, Goals, Agents, Activity, and Settings screens.
- Demo mode plus Local/LAN, zrok, Cloudflare, Tailscale, ngrok, and custom endpoint metadata.
- Session-only bearer token handling and HTTPS-only remote endpoints.
- Hardened GitHub Actions for quality, Android, iOS Simulator, and release artifacts.
