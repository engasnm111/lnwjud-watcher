# LNWJUD Watcher v0.1.0

First cross-platform preview of the read-only LNWJUD Watcher.

### Included
- Web/PWA build.
- Android debug APK for evaluation.
- iOS Simulator build for evaluation.
- Shared responsive monitoring UI for goals, agents, and observable activity.
- Watcher Protocol v1 client with validation and reconnect handling.
- zrok, Cloudflare Tunnel, Tailscale, ngrok, Local/LAN, and custom HTTPS endpoint profiles.

### Boundary
This release is intentionally read-only. Real runtime monitoring requires a lnwjud runtime exposing Watcher Protocol v1. iPhone/App Store distribution is not signed in this release; production iOS distribution requires Apple signing credentials.
